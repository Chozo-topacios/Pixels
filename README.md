# 👾 Pixel Agents

Una banda de agentes pixel-art (piano, batería, guitarra y voz) trabajando en su estudio de música.
Toca a cada músico para que suene; usa los botones para que celebren o se preocupen.

Se publica en https://chozo-topacios.github.io/Pixels/ con GitHub Pages.
Es un solo archivo `index.html`, sin dependencias.
