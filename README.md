# 👾 Pixel Agents

Un equipo de agentes pixel-art de ciberseguridad (firewall, análisis, recuperación y respuesta)
defiende sus servidores en pleno ataque: los virus entran por la derecha y los agentes los bloquean.
Toca a un agente para que dispare; usa los botones para lanzar un contraataque o una nueva oleada.

Se publica en https://chozo-topacios.github.io/Pixels/ con GitHub Pages.
Es un solo archivo `index.html`, sin dependencias.
